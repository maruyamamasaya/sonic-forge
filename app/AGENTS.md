# macOSアプリの追加ルール

この配下はSwiftUI / AppKit / AVFoundationを使用する。共通ルールはルートAGENTS.md。
- 画面はStudioView、再生状態はPlayerModel、ファイル解析・合成はAudioAsset、範囲と表示状態はWaveformEditor、選択音声はSelectionAudio、楽器エンジンはSampleInstrument、鍵盤はInstrumentKeyboard、保存形式はInstrumentDocument、ADSRの状態計算はADSREnvelope、MIDI機器・受信とバイト解析はMIDIInput、演奏データ形式・検証はPerformanceDocument、演奏編集UIはPerformanceEditor、楽器一覧・試聴はInstrumentLibrary、一覧UIはLibraryView、AI生成の共通検証はPerformanceGeneration、接続はCodexPerformanceClient/OpenAIPerformanceClient、候補状態はPerformanceComposer、生成UIはPerformanceComposerView、複数パートの割り当て/時計/ミックスはEnsembleModel、パート別押鍵/ペダル所有権はEnsembleVoice、画面はEnsembleView、配置の計算/描画はEnsembleTimeline/EnsembleTimelineView、セクションの検証/編集はEnsembleSections/EnsembleSectionsView、構成保存形式はEnsembleDocument、全体WAVレンダーはEnsembleExportに分離する。
- UIと再生状態の更新はMainActor。波形解析・音源合成はバックグラウンドで行う。
- 波形は線形振幅。メーターのみdB表示。実測しないデバイス名・サンプルレートや架空の状態を表示しない。
- ファイル読み込みが失敗したら元の音源を保持し、エラーを表示する。元ファイルを書き換えない。
- デザイン変更はユーザーの指示を優先し、承認済みの中央波形・右インスペクター・下部トランスポートを維持する。
- 検証はTESTING.mdのNative変更手順に従う。音が出ることと音質・遅延品質を保証することは区別する。
