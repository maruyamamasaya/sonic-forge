# 0023: パート内の複数演奏クリップで楽器を共有する

Date: 2026-10-17

音源・Root・ADSR・ループ・mixは既存のEnsemblePartに一度だけ保持し、additionalClips（0〜7個）へ演奏・配置・回数・sectionID・UUIDを持つ。既存の最初の演奏フィールドと操作入口は維持し、allClipsで共通化する。既存UI/API/旧形式との変更範囲を抑えるため、先頭を含む全配列への全面置換は行わない。
各パートは1つのEnsembleVoiceを使い、時間順に全クリップを配送する。同一パート内の区間重複は、同音程の離鍵やペダル所有状態が干渉するため拒否する。接する境界は前の終端を先に処理し、Release余韻は維持する。クリップ別の独立ミックス・重ね録音は今回の範囲外。
v5でadditionalClipsを必須保存し、旧v1〜v4は追加なしへ移行。音源は複製しない。最大4楽器パート・各8クリップ。ライブ/タイムライン/保存/WAVは同じ全クリップの検証・配置規則を共有する。
