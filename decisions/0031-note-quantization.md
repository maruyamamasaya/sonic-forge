# 0031: 選択音符の開始位置クオンタイズ

選択した音符の開始拍だけを最寄りの格子へ揃える。1/4・1/8・1/16・1/32音符と1/8・1/16三連符を提供し、拍の基準は四分音符=1拍とする。クリップ先頭を格子の原点とし、ちょうど中間は後ろへ丸める。長さ・音程・強弱・チャンネル・ペダルは保持する。

NoteQuantizeGridが刻みと丸めを担当し、editNoteGroupのquantizeから既存editClipNotesへ一括委譲する。一度の適用が1回のUndo/Redoになる。浮動小数点の誤差1e-9拍以内は元値を保持し、既に揃った音符で無意味な履歴を増やさない。無変更時はRedoとdirtyを保持する。

格子選択は下段の表示状態のみで保存しない。ドラッグの1/4拍スナップとは独立する。全配置検証で同音重複・セクション超過などを拒否し、部分適用はしない。保存形式と再生/出力経路は維持する。長さやペダルのクオンタイズ、スウィング、強度の割合調整は今回追加しない。
