# 0013: 拍単位の演奏ファイル

Date: 2026-10-16

## Context
固定プリセットを編集・保存し、将来AIが生成した演奏データも読み込める共通形式が必要。

## Decision
音符（開始拍・長さ・音程・強さ・チャンネル）とペダルをJSON v1として.sfperformanceへ保存する。
テンポ・移調・全体強弱は非破壊の調整値とし、MIDIイベントへの変換時に適用する。既存音色ファイルv4とは分離する。
PerformanceDocumentが値、同音重複、8音制限、ペダル終端を検証し、再生前には楽器音域も検証する。
UIは独立した編集シートとし、再生中は編集を無効化。保存・読込失敗時は既存データを維持する。

## Alternatives / Consequences
生MIDIバイト列の外部読込は採用せず、高水準の音符データを検証して生成する。SMFやピアノロール、録音、AI生成自体は対象外。
演奏と音色の自動ひも付け、起動時の演奏自動復元は行わず、Open…で明示的に読み込む。
