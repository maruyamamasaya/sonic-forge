# 0034: クリップ間の音符コピーと貼り付け

EnsembleModelがセッション内の音符クリップボードを値コピーで保持する。OSのクリップボードとは分離し、構成には保存しない。選択音符の最初の開始拍を0とした相対位置、長さ、チャンネル、演奏時のMIDI音程・強弱を保持する。コピーは元データ・dirty・Undo履歴を変えない。

貼り付け先のPaste @はクリップ内の先頭位置を拍数で指定する。元の相対リズムを足して追加し、既存音符を置換しない。元クリップのtranspose/velocityPercent適用後の音程と強弱を保存し、貼り付け時に対象設定を逆算する。強弱は1〜127の生値から同じMIDI値を作れるものを探索し、再現できない場合は拒否して対象のVelocityを100%へ調整する案内を出す。設定を勝手に変えたり近似して既存音符へ影響させない。

pasteClipNotesは既存editClipNotesの全配置検証・50操作履歴・保存/出力を共有し、1回の貼り付けを1回でUndo/Redoできる。重複・音域外・音数超過・範囲超過は全体を拒否し、データとクリップボードを保持する。コピー元を編集/削除しても値コピーは保持し、構成読込後も同一セッション内で使用できる。再起動でクリップボードは空になる。

ペダルや楽器設定のコピーは今回の対象外で、対象クリップの既存ペダル/楽器と共に演奏する。元の音程・押鍵リズム・強弱は保つが、音色とペダルによる響きは貼り付け先に従う。
