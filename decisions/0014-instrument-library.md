# 0014: 原本参照による楽器ライブラリと独立試聴

Date: 2026-10-16

## Context
既存の単一楽器保存を活かし、音色を探して試せる入口が必要。試聴で未保存の音色を失わせない。

## Decision
UserDefaultsに原本のパス一覧を保存する。通常保存・読み込み成功と明示的なファイル追加で登録。専用の音声エンジンを試聴時だけ作り、既存楽器のPCM・ADSR・ループを再利用する。詳細は[構造](../ARCHITECTURE.md#instrument-library)。

## Alternatives
管理フォルダへ全原本をコピーする案は容量重複と元ファイルとの版管理を増やす。フォルダ再帰走査・DB案は今回の規模に不要。本体を一時的に差し替える試聴は未保存状態の復旧を複雑にするため採用しない。

## Consequences
移動したファイルは再追加が必要。一覧除外は原本を消さない。大量一覧や外部ボリュームの応答は今後評価する。
