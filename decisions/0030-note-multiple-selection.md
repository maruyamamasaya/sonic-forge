# 0030: 音符の複数選択と一括編集

選択は下段View内の音符インデックス集合で保持し、構成へ保存しない。Shiftクリック、Multiモードでのクリック切替、空白からの矩形ドラッグ、All/Clearを選択入口とする。選択単独では演奏もdirtyも変えない。

EnsembleModel.editNoteGroupが選択集合の移動・複製・削除を一度のeditClipNotesへ渡す。相対位置と音程差、チャンネル・長さ・強弱を保持する。複製は元を残し、指定した拍/半音オフセットでコピーする。全クリップ検証を通った場合だけ適用するため、負の開始拍・同音重複・セクション超過・256音超過・全音削除は部分適用せず拒否する。一括操作は1回のUndo/Redo対象になる。

数値のΔ beats/Δ pitchとMove/Duplicateを用意し、ドラッグは選択された音符群全体に1/4拍単位の移動差を適用する。単音の数値Applyと右端リサイズは単独選択時に限る。履歴適用時とクリップ変更時は選択を解除する。既存保存形式・演奏経路は維持する。
