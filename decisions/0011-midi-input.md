# 0011: CoreMIDIの選択式ノート入力

Date: 2026-10-16

## Context
外部機器の演奏を既存の8音エンジンにつなぎ、実機なしでも受信経路を検証する必要がある。

## Decision
CoreMIDIで単一sourceを明示選択し、MIDI 1.0のNote On/OffとCC120/123を受信する。
バイト解析を受信層へ分離し、FIFOのMain Queue配送からチャンネル別所有権へ接続する。世代番号で旧接続の遅延配送を拒否する。
機器切断・切り替えはMIDIの保持音と余韻を停止し、他入力は保持する。初期接続はNone、選択は保存しない。
仮想sourceを同じCoreMIDIポートへ接続し、テスト三和音を送信する。UIは鍵盤上に一行追加する。
音程範囲は既存Varispeedの0.25〜4倍を維持し、MIDIは基準音±24半音を許可する。

## Alternatives / Consequences
MIDIをモデルへ直接注入するだけのテストではポート・機器切断を検証できないため、実仮想sourceを採用する。
MIDI 2.0/UMP固有機能や出力、強弱・ペダル・チャンネル選別は後続とする。MIDI機器設定は楽器音色の保存形式から分離する。
OSの通知・受信コールバックはMainActor状態を直接変更しない。実機のドライバーや遅延は仮想sourceだけでは保証できない。
