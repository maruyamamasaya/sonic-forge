# 0012: 強弱・サステインと自動演奏プリセット

Date: 2026-10-16

## Context
MIDIの強弱とペダルを既存の和音・ADSR・ループへ接続する。実機を持たず演奏できない利用者も音色を試せる必要がある。

## Decision
ベロシティを音ごとの線形倍率として保持する。CC64はチャンネル別に管理し、離鍵後は専用の保持所有権へ移行、解除時にReleaseする。
CC123はペダルを尊重、CC120・接続リセット・全音停止は保持とペダルを破棄、CC121はペダルのみ解除する。
固定3種の演奏プリセットを時刻＋MIDIバイト列のデータとして用意し、Taskから仮想MIDI sourceへ送る。
停止時はTaskキャンセルと受信世代更新で残音や古い配送を防ぐ。演奏状態は保存せず楽器形式v4を維持する。

## Alternatives / Consequences
非線形カーブ・ハーフペダル・強さ別のサンプル切り替えは後続。現行の同音共有ボイスでは最初の入力の強さを維持する。
AIへの外部接続は導入せず、固定プリセットの自動演奏を先に用意する。将来AIが生成した演奏データへ差し替えられる入口とする。
MainActor Taskの時刻制御は試聴用途で、DAWのサンプル精度や録音機能は対象外。
