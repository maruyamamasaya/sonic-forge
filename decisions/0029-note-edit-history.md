# 0029: クリップごとの音符編集履歴

下段にUndo/Redoボタンを追加し、EnsembleModelでクリップごとに直近50回の成功した音符編集の前後PerformanceDocumentを保持する。追加・削除・移動・長さ・強弱の数値適用を同じeditClipNotes入口で記録する。ドラッグ確定またはApplyを1操作とし、無変更・検証失敗は記録しない。新しい編集はそのクリップのRedoを破棄する。

履歴適用時もセクションと全クリップを検証し、失敗時はデータと履歴を保持する。現在の演奏が履歴の期待値と一致する場合のみ適用できる。演奏置換は対象履歴を消し、構成読込成功時は全履歴を消す。履歴はセッション内のみで、構成ファイル形式は変更しない。保存後も履歴は使用でき、取り消し・やり直しは変更としてdirtyになる（保存時点へ戻った場合も安全側で未保存表示を維持）。

macOSのテキスト入力のUndoと衝突させないため、音符履歴は下段の専用ボタンを使用する。構成全体のUndoやテーマ/ミックスの履歴は今回の対象外。独立したクリップを誤って戻さないよう、全体共通スタックではなく対象クリップに限定する。
