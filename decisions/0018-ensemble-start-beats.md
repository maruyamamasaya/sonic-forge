# 0018: パート開始位置を拍単位で保存する

Date: 2026-10-17

各パートへstartBeat（有限数0〜256、小数可）を追加する。演奏の元データは変えず、共通テンポで秒へ換算した開始オフセットを音符・離鍵・ペダル全体へ加える。終了位置も加算後のイベントから計算する。
秒単位の保存ではテンポ変更で曲の構成が崩れるため拍を採用。小節は拍子情報がまだないため導入しない。タイムラインや演奏の繰返しは今回の範囲外。
構成形式はv2へ上げ、startBeatを必須とする。v1は全パート0で読み込む。v1へ任意フィールドを足すだけでは旧アプリが開始位置を無視して演奏するため、未知版として拒否できるバージョン変更を選ぶ。保存し直したv2は旧アプリでは開けない。
既存Duoは互換性のため同時開始を維持し、Demo Entry +4で0/4拍の新規Duoを追加する。停止/世代取消は待機イベントにも適用する。
