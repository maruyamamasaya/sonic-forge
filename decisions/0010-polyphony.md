# 0010: 8音の独立ボイス

Date: 2026-10-16

## Context
単音を置き換える従来の構成では和音や独立した余韻を演奏できない。

## Decision
既存の音程・ADSR・ループ処理を8組のSourceNode/Varispeedスロットへ拡張し、読み込み済みPCMを共有する。
各音でADSRとループ設定を押鍵時に固定する。同音は再使用、空きなしでは最古のRelease、次いで最古の保持音を置換。
画面・PC・デモの入力所有権をモデルに持ち、最後の離鍵だけをエンジンへ渡す。
マウス1個でも和音を作れるクリック保持と、すぐ試せるデモ三和音を用意する。PCは物理キー位置で対応する。
合算の音量余裕として各音を1/8に固定。メーターだけを独立購読し演奏中の全画面再レイアウトを避ける。

## Alternatives / Consequences
単一ノードの自作リサンプリングは既存の音程品質を変えるため採用しない。動的な音量正規化は音量の揺れを生むため避ける。
単音時も約18 dB小さくなる。8音超過時の強制置換ではクリックの可能性が残る。ボイス数可変・MIDI・ベロシティは対象外。
演奏中の保持状態は保存しないため、保存形式v4の変更は不要。
