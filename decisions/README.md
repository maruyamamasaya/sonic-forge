# 設計判断の記録

将来の作業者が理由を必要とする重要判断だけを記録する。
番号は既存の最大番号の次を使い、NNNN-short-title.md とする。
変更後の判断は元記録を消さず、新記録から置き換え先・元判断へリンクする。

新しい記録は以下を埋める。

```markdown
# NNNN: 判断の名前
Date: YYYY-MM-DD
Status: proposed / accepted / superseded

## Context
背景と制約。
## Decision
決めたこと。
## Reason
理由と根拠。
## Alternatives
検討した代替案と採用しなかった理由。
## Consequences
影響、制約、見直し条件。
```
