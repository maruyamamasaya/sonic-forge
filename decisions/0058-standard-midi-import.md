# 0058: Standard MIDI Fileを候補確認後にサンプラーへ取り込む
Date: 2026-10-20
Status: accepted

## Context
固定楽譜のスクリプト試作から、アプリ内でMIDIを選び、既存楽器・構成保存・WAVへ接続したい。SMFの音色・テンポ・同音重なりを既存サンプラーと区別する必要がある。

## Decision
SMF 0/1・PPQをローカルの境界付きパーサーで解析する。トラック×チャンネルで候補を分け、1〜4つの範囲/楽器/移調を確認後、全検証して一括で置換する。音符・強弱・CC64を既存PerformanceDocumentへ変換し、保存形式は変えない。テンポマップは時刻へ積分し、共通テンポ下の拍に換算する。反映しない制御や再押鍵の処理を注意表示する。取り込みは曲全体のUndoで戻す。[仕様](../MIDI_IMPORT.md)。

## Alternatives
GM音源を自動割当すると自作楽器の目的と異なり追加依存も必要。MIDIの全機能/テンポマップ保存を同時導入すると保存・UI・再生の責務を広げる。汎用ライブラリは依存を増やすため、この範囲は専用解析と破損/上限テストで扱う。

## Consequences
GMや譜面の忠実再現ではない。範囲・音数・同時数を超える候補は黙って削らず止める。テンポ曲線の再編集、音色マップ、MusicXMLは別機能。私有音源の分析/コーラス素材化は制作例として記録し、音声を外部へ送らない。
