# 楽器ライブラリ

Date: 2026-10-16

## Request
保存した楽器を一覧検索・試聴・読み込み。既存UIを維持しデモとAI操作文書も整備する。

## Changes
原本参照の永続一覧、保存/読み込み時の登録、複数追加、名前検索、独立試聴、未保存置換確認を追加。デモ2種と操作・構造・検証文書を更新。判断は[0014](../decisions/0014-instrument-library.md)。

## Validation
Fast・Full（全通常テストとアプリビルド）成功。実出力付き--playback成功（試聴実メーター、自動停止、閉じる際の取消、編集状態保持、デモ読み込み、既存CoreMIDI統合）。制限内の初回実行は音声コンポーネント初期化で中断し、実出力へのアクセスを許可した再実行で成功。
実UIでデモ追加→Soft検索→Preview→Load Instrument→Auto playと3音/メーター、未保存Sustain変更→置換Cancel→70%保持を確認。幅約1000の本体・ライブラリシートの配置を確認。再起動後にデモ2種と既存楽器の一覧・直前楽器の復元を確認。
初回Fullは並行作業によるビルド手順更新の途中で中断。更新を保持して再実行し成功。

## Result
ライブラリ経由で楽器の検索・試聴・読み込みが可能。試聴は本体の保存状態を変えない。

## Remaining Issues
原本移動時は再追加が必要。大量ファイル・外部ボリューム・長時間負荷は未評価。
