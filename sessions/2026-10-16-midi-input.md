# 外部MIDI入力

Date: 2026-10-16

## Request
接続したMIDIキーボードを選択し和音・ADSR・ループで演奏する。既存UIを維持し実機なしでも検証可能にする。

## Changes
CoreMIDI入力層・バイト解析・機器選択・仮想テストsourceを追加。FIFO配送と接続世代で順序と旧入力の破棄を管理。
チャンネル別所有権、CC120/123、切断時の余韻停止を既存エンジンへ接続。MIDIの音域は基準音±24半音。
全音終了時のメーター復帰を修正。入力機器設定は楽器ファイルから分離しv4を維持。

## Validation
Fast・Full・--playback成功。通常テストはrunning status、分割メッセージ、velocity-zero離鍵、システムバイト・CCを確認。
実仮想CoreMIDIで3音同時発音、ADSR離鍵、ループ、音量メーター、チャンネル/画面所有権、CC120での余韻停止を確認。
入力切り替え、None、旧配送破棄、source消失、発音抑制と再開、画面外の音も確認。既存音声テストも通過。
実UIでTest input→MIDI chord→Release MIDI、Noneと再接続、3鍵点灯、最小幅約1000での配置を確認。
入力メニューの子ウィンドウ通知で一時停止が残る問題を発見し、通知を本体ウィンドウへ限定して修正した。

## Result
実機なしで通常のCoreMIDI受信経路を通した演奏確認が可能。

## Remaining Issues
USB/Bluetooth等の実機とドライバー・実測遅延・長時間大量入力は未検証。
ベロシティ強弱、ペダル、ピッチベンド、チャンネル選別、MIDI 2.0固有機能・出力は未対応。
