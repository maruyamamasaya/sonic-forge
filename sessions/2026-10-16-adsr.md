# ADSRと楽器設定の保存
Date: 2026-10-16

## Request
立ち上がり・余韻を調整するADSRを追加し、その設定を楽器と一緒に保存する。既存UIを維持しデモで確認する。

## Investigation
単音エンジン、離鍵／Stopの扱い、楽器形式v1、設定変更とdirty、鍵盤と音声テストを確認。
UIタイマーではなく音声クロック上で段階を進める必要があるため、PCM供給をSourceNodeへ変更し既存Varispeedを維持した。

## Changes
ADSREnvelope.swiftにパラメーター・段階計算、SampleInstrumentにInstrumentVoiceのレンダー処理を追加。
Attack / Decay / Sustain / Releaseの4スライダーを鍵盤上へ追加し、次の押鍵から反映。離鍵は現在音量からRelease、Stop等は強制停止。
楽器形式v2へADSRを保存。旧v1はA/D/R=0・S=1で互換読込。関連ガイド、設計判断0007、テストとビルドを更新。

## Validation
Fast / Full Verify成功。--playback成功。既存の音程・選択・WAV書き出し・保存復元テストも成功。
EnvelopeTestsで各段階の時間とレベル、Attack途中の離鍵、ゼロ時間、不正値、ステレオ係数、音程倍率補正を確認。
実際の音声グラフをoffline renderし、3つの音程でAttack・Sustain・離鍵後の非ゼロ出力と終端無音を測定。
ADSRの保存値一致、旧v1の互換値、範囲外パラメーター拒否を確認。
実UIで4スライダー操作、デモ保存→終了→再起動→Attack 0.159秒 / Decay 0.410秒 / Sustain 56% / Release 0.796秒の復元と鍵盤演奏を確認。
検証楽器はbuild/SonicForge-demo-adsr.sfinstrument。旧v1ファイルは変更しない。通常幅・最小幅の表示を確認。

## Result
ADSRによる立ち上がりと離鍵後の余韻を調整でき、音源・Rootと一緒に保存・復元できる。

## Remaining Issues
サンプル末尾を超える余韻、ループ、和音、カーブ形状の選択、実時間のオートメーションは未実装。
レンダーはtry-lockで待たず、競合ブロックは無音。演奏遅延・高負荷・長時間動作は未評価。変更は未コミット。
